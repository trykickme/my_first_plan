# Локальные модели

Python 3, без дополнительных пакетов и сети.

python modern_lab.py agent
python modern_lab.py identity
python modern_lab.py events

Сохрани JSON результата рядом со своей заметкой. Изменяй один параметр и сравнивай прежние случаи. Не считай модель проверкой реального LLM или JWT.

При установленном rustc: rustc ownership.rs, затем запусти полученную программу. Для отрицательного случая включи закомментированное обращение к first после move и сохрани диагностику компилятора.

build_fixture.json — вымышленная неподписанная запись. Она не доказывает provenance. Неизвестные проверки нужно перечислить, а не пометить выполненными.
