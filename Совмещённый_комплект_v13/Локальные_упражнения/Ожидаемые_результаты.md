# Ожидаемые результаты новых локальных опытов

Выводы ниже получены при проверке 4 октября 2026 года. Это контрольный образец: сначала предскажи результат и запусти свою копию. Во всех новых опытах study_lab.py используются локальные данные без сетевых запросов.

## bytes

```bash
python3 study_lab.py bytes
```

```json
{
  "text": "AЯ\n",
  "characters": 3,
  "bytes": 4,
  "hex": "41 d0 af 0a",
  "roundtrip": "AЯ\n",
  "little_endian_0x12345678": "78 56 34 12"
}
```
